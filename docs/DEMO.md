# Recording the demo

The README GIF and the launch video are the most important marketing VibeOK has. Keep both under 30 seconds.

1. `npm run build && npm run demo`
2. Make the browser window large and hide bookmarks. Screen-record at 1280×800.
3. Run `node dist/cli.js localhost:3000 --pages 4` and let the cursor work.
4. Cut to the moments that matter: "Watch demo" turning amber, the signup form "succeeding" while the 500 is caught, the phone squeeze, the final score.
5. End on the terminal report, then on Cursor or Claude Code pasting `VIBEOK_FIX_PROMPT.md` and fixing the bugs, then the re-run passing.
6. Export the GIF at 960px wide, under 8 MB, as `docs/demo.gif`, and update the README.
